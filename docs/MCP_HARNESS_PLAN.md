# MCP 与 Harness 扩展计划

实施日期：2026-10-12。后端与前端为独立 Git 仓库，每个阶段在测试通过后分别提交。

## 1. MCP 兼容层

- 使用官方 TypeScript SDK，支持 stdio、Streamable HTTP、SSE。
- 保留现有 defineReadOnlyTool 参数声明与调用方式；扩展 RegisteredTool 的来源与幂等性元数据。
- MCP inputSchema 经 JSON Schema 验证后传给模型；使用稳定的服务器/工具命名隔离。
- 配置持久化、初始化握手、分页发现、按请求刷新工具清单、取消、超时和关闭连接。
- 一个 MCP 失败仅使其工具不可用，现有记忆与工作区工具仍可执行。
- 管理接口只接受本机管理员或配置的管理令牌；凭据使用后端环境变量引用，响应不暴露凭据。
- 导入默认禁用；默认只提供 readOnlyHint=true 的工具，写工具需要显式授权。
- 测试：真实 SDK 连接、旧工具兼容、参数校验、禁用、同名隔离、错误和超时。

## 2. MCP Hub 与教程

- 侧边栏收纳式 Hub，表单和 mcpServers JSON/文件导入，启用开关、连接测试、状态、工具列表。
- 操作在请求结束后更新状态，失败明确反馈；支持移动端与键盘操作。
- 文档介绍第三方服务、自建 stdio 服务、HTTP 服务、环境变量和部署注意事项。
- 测试：DOM 交互、真实前后端 HTTP 集成、类型检查与生产构建。

## 3. Harness 恢复策略

- 瞬时模型错误有限次指数退避；明确配置备用模型后在当前回合回退，不重跑整个工作流。
- 普通工具错误继续作为 tool 结果供模型处理；仅幂等工具可自动重试。
- 参数、权限、认证错误不重试；取消与总时间预算不触发回退。
- 测试：成功重试、耗尽、备用模型、不可重试错误、取消、非幂等工具执行一次。

## 4. 可观测性

- 参考本地 VS Code Copilot 的工具事件与请求记录分层，不保存隐藏推理。
- 每个问题使用 runId/requestId/sessionId 关联上下文、模型回合、工具、恢复、结束事件。
- 记录时间、耗时、状态、输入/输出摘要，敏感字段脱敏并限制记录大小。
- 运行记录独立持久化；前端按问题展示可折叠时间线，包含失败与取消。
- 测试：顺序、关联、并发隔离、重启恢复、失败、脱敏和前端展示。

## 验收

每阶段执行相关测试及后端 typecheck/build；前端阶段执行全部前端测试和 build。禁止批量删除文件或目录，测试临时产物保留。MCP 官方 SDK 文档：https://ts.sdk.modelcontextprotocol.io/client 。
